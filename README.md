# IU HPC Drive Backup — Public Documentation

This repository contains only the static application homepage and privacy policy for an independently maintained personal backup workflow.

- `index.html`: purpose, functionality, access disclosure, and contact.
- `privacy.html`: privacy policy and Google API Limited Use disclosure.
- `.nojekyll`: serve the plain HTML without Jekyll processing.

This is not an official Indiana University or Google service. It does not contain or distribute backup contents, research data, operational logs, credentials, or private configuration. Publishing these pages does not publish any Google Drive backup.

Do not commit private files or secrets. Do not include sensitive information in public issues.
