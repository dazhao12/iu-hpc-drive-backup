Privacy Policy

Application: IU HPC Drive Backup
Effective date: 2 October 2026
Operator: GitHub user dazhao12

Purpose and information accessed

This operator-managed desktop backup workflow uses rclone and the Google Drive API. With the account holder's consent, it accesses Google account identity information exposed by Drive, folder and file identifiers, names, paths, sizes, timestamps, checksums, ownership and permission metadata, storage quota information, and file contents required for approved copy, restore, and verification operations.

The requested Drive permission can permit reading, creating, editing, and deleting files. The workflow uses this access for selected backups and explicitly approved maintenance, not unrelated browsing, unrestricted deletion, or public sharing.

How information is used

Information is used to confirm the correct destination account, identify backup folders, transfer selected files, avoid unnecessary duplicate transfers, resume interrupted work, verify file integrity, monitor capacity and errors, and restore or maintain backups when instructed. The workflow may keep manifests, checksums, and operational logs for those purposes. It does not sell Google user data or use it for advertising.

Storage and security

Backup contents are stored in the authorized Google Drive accounts. Credentials and refresh tokens are stored separately in access-restricted configuration files on the operator's local or computing systems, not in this public website or repository. Google API transfers use HTTPS. Logs and manifests may contain file metadata and are operational records, not public website content. The operator must protect those records and exclude secrets from public logs or issue reports.

Sharing and service providers

Google processes data needed to provide Google Drive and account authorization. The operator's computing environment processes files and operational records needed for the transfer. Backup contents are not uploaded to GitHub Pages and are not made public by publishing this documentation. The application does not change Drive sharing permissions without separate operator approval. GitHub hosts this static documentation and may process ordinary website request information under its own privacy statement.

AI and machine learning

Automation may assist with managing backup jobs. The backup client does not use Google Workspace API data to develop, improve, or train non-personalized artificial intelligence or machine-learning models. Backup contents are not submitted to an AI service by the rclone transfer workflow. This policy does not authorize separate analysis or disclosure of backup contents to another service.

Retention, revocation, and deletion

Backups remain in the authorized Drive account until the account holder deletes them or explicitly instructs approved maintenance. Operational records are retained while needed for backup continuity and verification. The account holder can revoke the application's access through Google Account connections. Revocation prevents further authorized API access but does not automatically delete existing backups or records. Deletion requests must identify the exact files or records and be verified with the operator; never post sensitive details in public issues.

Limited use and policy updates

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Any material change in data use requires an updated disclosure and, where necessary, renewed consent.

Contact

Contact the maintainer through the documentation repository or the support contact displayed on Google's consent screen. Public issues must not contain research records, patient information, passwords, tokens, credentials, or private file lists.
