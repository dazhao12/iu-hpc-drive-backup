IU HPC Drive Backup

A personal, operator-managed backup workflow that uses rclone and Google Drive to preserve selected files from a high-performance computing environment in the operator's authorized Google Drive accounts.

What the application does

The workflow copies approved files, resumes interrupted transfers, and reads destination file metadata and checksums to verify backups. It is not a public file-sharing service. Google-account authorization takes place on Google's own consent screen; this website does not collect passwords or authorize access.

Google Drive access

The desktop backup client requests the Google Drive scope needed to list and read files, create folders, and write backups. This scope can also permit editing or deleting Drive files. That capability is not permission for unrestricted deletion: any deletion or sharing change requires the operator's separate instruction. Access is used only for the disclosed backup, restore, verification, and explicitly approved maintenance operations.

Private backups, public documentation

This public website contains only application information and a privacy policy. It contains no backup files, research records, account credentials, access tokens, or private configuration. Source files and backup credentials are not published to this repository.

Use and responsibility

This is an independently maintained personal tool, not an official Indiana University or Google service. The operator must have authorization to copy each selected file and must respect applicable institutional rules, data-use agreements, and access restrictions. A successful transfer alone does not establish that all data has been backed up or that a source may safely be deleted.

Please read the privacy policy before authorizing the application.
